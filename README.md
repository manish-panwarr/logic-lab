# Logic Lab

A hands-on collection of mini-projects built to improve programming fundamentals, logical thinking, problem-solving abilities, and practical development skills.

## Purpose

The goal of this repository is to learn by building. Each project focuses on applying programming concepts, breaking down problems, writing logical solutions, and understanding how real applications work.

## Projects

| # | Project | Focus |
|---|---|---|
| 01 | Counter App | Variables and DOM manipulation |
| 02 | Digital Clock | Date and time handling |
| 03 | Calculator | Operators and functions |
| 04 | Todo App | CRUD and localStorage |
| 05 | Password Generator | Strings and randomization |
| 06 | Quiz App | Objects and state management |
| 07 | Notes App | CRUD and data persistence |
| 08 | Expense Tracker | Data manipulation |
| 09 | Weather App | APIs and asynchronous JavaScript |
| 10 | Memory Game | Game logic and state management |

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser APIs
- Public APIs

## Learning Approach

- Understand the problem before coding.
- Break complex requirements into smaller tasks.
- Write pseudocode before implementation.
- Explore different approaches.
- Handle edge cases and errors.
- Focus on clean, readable, and maintainable code.

## Progress

This repository is continuously evolving as I learn, experiment, and build new applications.

**Learn → Think → Build → Improve.**
